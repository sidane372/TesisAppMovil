# Evidencias Git del Entregable 3

Esta carpeta conserva transcripciones de comandos de lectura usados para actualizar ../03_Control_Versiones.md. Los archivos numerados identifican comando, fecha de consulta en America/Lima, código de salida, salida estándar y errores. El número de commits y sus fechas proceden de Git, no de una planificación reconstruida.

El historial contiene nueve commits alcanzables en este corte. commits/ conserva dos salidas git show por cada commit: resumen de cambios y lista completa de archivos y estados. Historial_Real.json permite consultar los mismos metadatos sin interpretar una captura de pantalla.

00_Documento_Anterior.md es una copia del informe previo y puede contener afirmaciones superadas. El documento académico actualizado es ../03_Control_Versiones.md.

Verificacion_Integridad.json registra la conservación de HEAD, índice y archivos versionados ajenos al informe. SHA256SUMS.txt permite identificar los archivos de esta captura y el informe; no contiene su propio hash. El ZIP y el manifiesto académico anteriores no se actualizaron en esta tarea.

No se ejecutaron git add, commit, push, merge ni fetch. No se cambió el código Android o backend. Los cambios preexistentes del usuario se conservaron. La consulta ls-remote verifica el estado del servidor en el instante registrado y no envía archivos del proyecto.
